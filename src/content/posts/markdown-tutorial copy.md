# ❇️ 阅读前介绍

- 售卖二类精神药品、精麻药品实际是算作售卖`毒品`，没有争议的实刑。使用或吸食本身不构成犯罪，属于治安违法。
- 关于植物类型的迷幻蘑菇、相思树皮、仙人掌等，种植并不构成违法。因为其并不像鸦片、大麻这种单独列在名单中，所以存在很大辩护空间。当然是售出未经处理的植物，而不是提纯过或者熬过汤的。
- 关于RC，即便没有制造、贩卖，只是持有就构成犯罪，请注意。<非法持有毒品罪>

# ☢️ 出售物质

:::warning[注意]
请明确该物质有何特性，是否易制毒、含剧毒、易制爆,每一种都有`发布名单`，面对的风险也各不相同 ，或者亦然只是单纯普通物质。
:::

1. 危险化学品（含剧毒、易制爆等）：未经许可买卖、运输、储存毒害性等危险物质，可构成非法制造、买卖、运输、储存危险物质罪（《刑法》第125条）。
   - 基本刑：3年以上10年以下有期徒刑。
   - 情节严重或数额巨大：10年以上有期徒刑、无期徒刑或死刑。
2. 易制毒化学品（前体化学品）：非法生产、买卖、运输醋酸酐、乙醚、三氯甲烷等用于制造毒品的原料/配剂，构成非法生产、买卖、运输制毒物品罪（《刑法》第350条）。
   - 情节较重：3年以下有期徒刑、拘役或管制，并处罚金。
   - 情节严重：3–7年有期徒刑，并处罚金。
   - 情节特别严重：7年以上有期徒刑，并处罚金或没收财产。

:::tip[恭喜]
如果您只是售出了不在任何`名单`中的`普通物质`，那么恭喜您已经成功规避了一些刑事风险。
:::

# 💊 出售处方类药物

1.  行政责任：责令停止经营、没收药品和违法所得、高额罚款等。
2.  销售金额或盈利达到`五万`以上，是非法经营罪（《刑法》第225条）可处5年以下有期徒刑或拘役，并处罚金；情节特别严重的处5年以上有期徒刑。
3.  涉及假药、劣药，可能构成销售假药/劣药罪。
    - 一般情节：三年以下有期徒刑或拘役，并处罚金
    - 对人体健康造成严重危害：三年以上十年以下有期徒刑，并处罚金

4.  若涉及麻醉药品、精神药品等特殊管理药品，可能直接被认定为贩卖毒品罪。

5.  某些用原粉`自制的胶囊和药片`是绝对的制售假药，实验试剂下方的`本品仅为科研使用,不可用于人体`，这取决了你售卖的是“药品”还是自己弄的不同形态的“试剂”。请一定加上该提示！

:::tip[恭喜]
任何试图通过隐蔽交易、小额分散、不留记录、使用个人账户、假借“互助”“代购”名义等方式降低被发现概率的行为，本身就属于违法经营的一部分。
:::

# ☎️ 售卖、代购国外药物

自药神案后制售假药罪基本不会应用在国外药物上，但仍有非法经营或妨害药品管理罪。
:::tip[提示]
妨害药品管理罪要求行为`足以严重危害人体健康`。如果数量很少、药品本身质量合格、没有针对特殊人群（如儿童、孕妇、危重病人）、没有实际造成任何健康损害，且经评估不存在严重危害人体健康的现实危险，可能根本达不到刑事立案或起诉标准，仅按行政违法处理（罚款、没收等）。
:::

1.  少量药品只要有处方一般问题都不大，除少数精麻药品外。
2.  妨碍药品管理《中华人民共和国刑法》第142条之一规定的罪名（由《刑法修正案（十一）》增设）
    - 足以严重危害人体健康的，处三年以下有期徒刑或者拘役，并处或者单处罚金；
    - 对人体健康造成严重危害或者有其他严重情节的，处三年以上七年以下有期徒刑，并处罚金
3.  非法经营流水或盈利在`五万`以下，一般不构成刑事处罚。

# ☠️ 贩卖RC罪

:::warning[注意]
走私、贩卖、运输、制造毒品，无论数量多少，都应当追究刑事责任，予以刑事处罚。一旦确认基本没有缓刑和无罪的可能，即使只贩卖极少量。
:::

1.  三年以下有期徒刑、拘役或者管制，并处罚金（少量）：海洛因或者甲基苯丙胺不满10克，或者其他`少量毒品`的。
    - 如果具有“情节严重”情形（例如向三人以上贩卖、三次以上贩卖、向在校学生贩卖、在戒毒场所贩卖等），则升至三年以上七年以下有期徒刑，并处罚金。
2.  七年以上有期徒刑，并处罚金（数量较大）：鸦片不满1000克、海洛因或者甲基苯丙胺`10克`以上不满50克，或者其他毒品数量较大的。
3.  十五年有期徒刑、无期徒刑或者死刑，并处没收财产（数量大或情节特别严重）：海洛因或者甲基苯丙胺（冰毒）`50克`以上，或者其他毒品数量大的；
    - 毒品犯罪集团的首要分子
    - 武装反抗
    - 参与国际贩毒活动的

      ### 贩卖RC单篇
      - `不清楚`售卖何种物质(`实际是合法物质`)，但是对外宣传说是RC的，属于贩毒未遂。可以比照既遂犯从轻或者减轻处罚，但仍然基本会是实刑。
      - `清楚`自己物质合法但是任然对外宣传说是RC进行售卖的，属于诈骗。`挂羊头卖狗肉`。

| 诈骗情节     | 诈骗数额标准（参考） |                                       诈骗量刑幅度 |
| :----------- | :------------------: | -------------------------------------------------: |
| 数额较大     |   3000元–1万元以上   |       三年以下有期徒刑、拘役或管制，并处或单处罚金 |
| 数额巨大     |   3万元–10万元以上   |                 三年以上十年以下有期徒刑，并处罚金 |
| 数额特别巨大 |      50万元以上      | 十年以上有期徒刑或无期徒刑，并处罚金，没收全部财产 |

:::warning[注意]
主要注意的是，假设100克的冰糖里含有1克RC，也会算到贩卖、制造100克的RC,不过是1%的浓度。
:::
:::tip[恭喜]
当然如果你售卖的物质合法，且宣称合法，对人体伤害较小。那么恭喜你，成功规避了一些刑事风险。
:::

# ✈️ 关于立案

### 一、行政立案（治安案件立案）：

- 公安机关对违反治安管理的行为立案调查，后果是行政处罚（拘留、罚款），不会留下`刑事案底`。吸毒被查就是典型的行政立案。

### 二、刑事立案：

- 公安机关认为存在犯罪事实、需要追究刑事责任，启动侦查程序。这才是通常意义上的`案底`。

### 三、行政转刑事

- 对暂时无法确定为刑事案件或行政案件的，可以按照行政案件的程序办理；在办理过程中认为`涉嫌构成犯罪`的，应当转为刑事案件办理。反过来，刑事案件如果尚不够刑事处罚但依法应当给予行政处理的，也可以按行政程序处理。

# ❄️ 关于刑事案件流程

> 拘留 → 审查逮捕（检察院）→ 侦查 → 审查起诉（检察院）→ 审判（法院）

### 一、拘留程序

- 公安机关拘留时必须出示拘留证，拘留后，会在24小时以内进行一次讯问，情节严重或事实没有争议的会很快送看守所羁押。
- 公安拘留后3天内应提请检察院批准逮捕。特殊情况可延长1-4天。对于"流窜作案、多次作案、结伙作案"的嫌疑人，可以延长至30天。检察院审查批捕期限为7天。加起来最长37天。
  > 根据案件轻重可能分为：拘传、取保候审、监视居住、刑事拘留、直接逮捕。取决于警方掌握的证据和当场情况，包括你手机中的情况。

### 二、审查逮捕程序

1. 公安机关写出《提请批准逮捕书》，连同案卷材料、证据移送同级人民检察院。
2. 检察院审查期限：
   - 已被拘留的：接到提请批准逮捕书后7日以内作出决定。
   - 未被拘留的：15日以内（重大、复杂案件不超过20日）。
3. 检察院可以讯问犯罪嫌疑人（在特定情形下应当讯问），并审查证据。
4. 审查结果：
   - 批准逮捕：公安机关立即执行，并通知家属。
   - 不批准逮捕：说明理由；需要补充侦查的，同时通知公安机关。公安机关应当立即释放或变更强制措施（如改为取保候审、监视居住）。

### 三、侦查程序

- 公安机关认为犯罪事实清楚、证据确实充分的，写出起诉意见书，移送检察院审查起诉。

### 四、审查起诉

- 检察院审查（一般1个月，可延长半个月），根据证据证言决定提起公诉、不起诉或退回补充侦查。

### 五、审判

- 法院开庭审理。双方辩护，公诉提出证据资料，原告辩论，此时决定刑期长短，作出判决。不服可上诉，可能会有一审二审。

### 关于认罪认罚

- 犯罪嫌疑人认罪认罚的，检察院应当告知其享有的诉讼权利和认罪认罚的法律规定。签署具结书后，案件通常走速裁程序。

- 速裁程序一般不进行法庭调查、法庭辩论，法院在十日内审结。一旦签了认罪认罚具结书，后面的法院审判基本是走过场。

- 所以，如果行为本身不构成犯罪（销售某些合法化工原料不是贩卖RC），认罪认罚就是在给自己制造一份不该存在的犯罪记录。如果行为确实构成犯罪，认罪认罚的从宽幅度是实实在在的。但不管哪种情况，在签署具结书之前，一定要先搞清楚自己的行为是否构成犯罪。

## ☝️ 关于律师介入辩护（拘留马上找）

:::warning[注意]
越早介入越好。多数专业刑事律师建议在刑事拘留后立即委托，这样能在审查逮捕（“黄金37天”）前充分开展工作，规某些不长脑子的发言，在拘留期间的压力是非常大的。
:::

1. 一般在拘留期间就可以申请律师会面，这个阶段是`黄金时间`。律师介入越早，越有利于固定有利证据、争取取保候审、防止超期羁押，并为后续辩护打下基础。很多案件在审查逮捕前律师就会提交书面意见。
2. 审查起诉，件移送人民检察院审查起诉之日起，犯罪嫌疑人就有权委托辩护人（正式辩护身份）。
   - 查阅、摘抄、复制案卷材料（全面了解证据）。
   - 会见犯罪嫌疑人。
   - 向检察院提出辩护意见（包括无罪、罪轻、不起诉等意见）。
   - 申请检察院调查取证或补充证据。
   - 参与认罪认罚从宽程序的协商。
3. 法院审判阶段
   - 出庭辩护（举证、质证、辩论）。
   - 发表辩护意见（无罪辩护、罪轻辩护、量刑辩护）。
   - 申请排除非法证据、申请证人出庭等。
   - 二审阶段继续代理上诉或辩护。

:::warning[关于诱供]
法律仅将"刑讯逼供等非法方法"列为应当排除的情形，并未明确将"引诱、欺骗"纳入排除范围。这意味着：如果侦查人员通过诱供获取了你的口供（比如告诉你"你认了就放你走"），这种做法是违法的，但你的口供不会自动被排除。
:::
