## 肉豆蔻醚

肉豆蔻醚（Myristicin） 是一种天然存在的苯丙素类化合物（phenylpropene），化学名为5-烯丙基-1-甲氧基-2,3-亚甲二氧基苯。基本信息分子式：C₁₁H₁₂O₃  
分子量：192.21  
结构特点：带有亚甲二氧基和甲氧基的烯丙基苯，脂溶性较好。

天然来源主要存在于：肉豆蔻（Myristica fragrans）种子及其精油（含量较高）
也少量存在于欧芹、莳萝、胡萝卜籽、黑胡椒等香料植物中

## 药理

- 高剂量时具有致幻、解离、镇静等作用，是肉豆蔻大量食用后产生精神症状的主要活性成分之一。效应更接近谵妄样体验，而非经典迷幻剂。
- 肉豆蔻醚是较弱的MAO抑制剂。
- 抑制MAO后，会减少5-羟色胺、多巴胺、去甲肾上腺素的降解，使突触间隙这些单胺类神经递质水平升高。这可能贡献部分情绪改变、兴奋或感知变化，但单独不足以解释强烈致幻。

高剂量摄入后（通常数小时后起效）：

- 视觉/听觉扭曲、幻觉
- 时间与空间定向障碍
- 解离感、漂浮感
- 常伴随强烈焦虑、恐慌、恶心、心动过速
- 体验多半不愉快，持续可达数十小时
  这些效应是肉豆蔻中多种成分（肉豆蔻醚 + 榄香素等）共同作用的结果，而非单一化合物所致。

## 药动力学

1. 吸收口服后吸收良好（脂溶性较高，有利于胃肠道吸收）。
   动物实验显示口服生物利用较高，吸收较迅速。

2. 分布具体人体分布容积等参数缺乏系统研究。
   动物实验中可见一定量分布至肝脏、肠道等组织，部分残留。

3. 代谢肉豆蔻醚在肝脏被广泛代谢，主要依赖细胞色素P450酶：主要酶：CYP3A4（为主），CYP1A2也有参与。
   主要代谢途径：亚甲二氧基开环（demethylenation）：生成5-烯丙基-1-甲氧基-2,3-二羟基苯。
   1'-位羟基化：生成1'-羟基肉豆蔻醚（1'-hydroxymyristicin，重要代谢物，与活性和潜在毒性相关）。
   其他：进一步羟基化、去甲基化、还原等。代谢物多以结合形式（葡萄糖醛酸结合、硫酸结合等）存在。

4. 排泄小鼠实验中：约73%以CO₂形式经呼吸道排出（来自亚甲二氧基的裂解），约15%经尿液，约3%经粪便（48小时内）。
   尿液中可检测到羟基化、去亚甲二氧基等代谢物及其结合物。
   整体消除以代谢后排泄为主。

5. 半衰期与其他参数目前缺乏完整的人体药代参数（如精确的t₁/₂、清除率、分布容积等）。
   动物实验显示代谢较快。
   在肉豆蔻中毒的人体案例中，曾检测到血清中的肉豆蔻醚，并尝试估算其消除情况，但数据有限，个体差异大。

> 总结肉豆蔻醚口服吸收较好，主要在肝脏经CYP酶代谢（以去亚甲二氧基和1'-羟基化为主），代谢物多经结合后随尿液排出，部分碳以CO₂形式呼出。

## 剂量

1. 肉豆蔻醚原粉剂量
   - 轻度剂量：50-200mg
   - 中度剂量：200-500mg
   - 高度剂量：500-800mg
   - 重度剂量：800mg+

2. 肉豆蔻粉剂量
   - 约5克肉豆蔻粉的最低剂量时，肉豆蔻中毒症状就会开始出现
   - 轻度剂量：5-15g
   - 中度剂量：15-20g
   - 高度剂量：20-30g
   - 重度剂量：30g+

3. 时间
   - 起效时：3-8h
   - 来效时：1-4h
   - 顶峰时：9-12h
   - 退效时12-48h
   - 总效时：12-72h
   - 后续影响：24-72h

4. 相互作用
   - 肉豆蔻醚 与 其他MAOI、SRI、SRA 合用可导致血清素综合征
   - 肉豆蔻醚 与 乙醇、阿片类药物、BZD类、右美沙芬及其他镇静剂 合- 用 可导致呼吸抑制
   - 肉豆蔻醚 与 兴奋剂 合用可增加心血管毒性
   - 肉豆蔻醚 与 苯海拉明、茶苯海明 合用可导致心脏毒性
